# R22 Ar Condicionado

Landing page da R22 Ar Condicionado: instalação, limpeza e manutenção de ar-condicionado. Site estático em HTML, CSS e JS puro, sem etapa de construção.

Publicado em: https://aurumscale-beep.github.io/r22ar/

## Arquivos

Todos os arquivos ficam na raiz do repositório, sem pastas, porque o envio de arquivos pelo navegador aplaina os caminhos. Por isso os nomes levam prefixos:

- index.html: a página
- styles.css, app.js e config.js: estilos, comportamentos e dados de contato
- img-*: imagens do site
- img-marcas-*: logo das marcas parceiras
- img-pag-*: bandeiras de pagamento
- fontes-*: fontes usadas na página

## Como actualizar

Substitua os arquivos por meio de Add file, Upload files. O GitHub Pages reconstrói o site sozinho a partir da branch principal.
